# Docs

Runbooks, architecture notes and postmortems as Markdown. Each heading section is indexed
separately, so put the symptom in the heading.

```
runbooks/      one per service, plus host-down.md
architecture/  components, dependencies, data flow
postmortems/   YYYY-MM-DD-short-title.md
```

See the "Write the docs that matter" section of docs/knowledge-base.md, and
examples/demo/docs/ for samples.
